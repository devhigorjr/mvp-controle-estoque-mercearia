MVP — Controle de Estoque para Mercearia

Sobre o projeto

Este projeto acadêmico tem como objetivo desenvolver um sistema simples para auxiliar pequenas mercearias no controle de estoque.

Objetivo

Facilitar o cadastro de produtos, a consulta de quantidades disponíveis e a atualização das informações do estoque.

Funcionalidades previstas

* Cadastro de produtos.
* Consulta de produtos e quantidades.
* Atualização do estoque.
* Mensagens de confirmação e alerta.

Tecnologias

As tecnologias serão definidas durante o desenvolvimento.

Status

Em desenvolvimento — etapa inicial de planejamento do MVP.
